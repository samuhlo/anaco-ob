Preparación de notas

Puedes cambiarlo antes de preparar cada captura. El código relevante se conserva con su explicación en cualquiera de los modos.

En automático se reutilizan los pies, descripciones accesibles y nombres de archivo claros. Las imágenes con descripción suficiente no se envían a visión. Los nombres se indican como pistas, no como observaciones verificadas. Las páginas de PDF y fotogramas pueden necesitar visión para comprender el contenido completo. Si ninguna imagen necesita análisis, se mantiene el modelo de texto.

Libros, PDF y vídeo

Se leen todas las páginas del libro y después se sintetizan juntas. Los lotes completados se conservan si hay que reintentar.

Motor actual: CPU · int8. La tarjeta gráfica no se utiliza en esta versión. Tiny prioriza rapidez; small requiere más tiempo y memoria. El modelo se descarga la primera vez. Se usan subtítulos cuando están disponibles.

Importación manual

Para un archivo que ya tienes descargado, abre la herramienta de importación. Admite PDF, audio, vídeo y subtítulos.

Instalación local

Si el servicio no conecta, ejecuta desde la carpeta del proyecto:

python3 scripts/install.py

La extensión necesita el servicio local para preparar notas y guardar archivos. Consulta PRUEBA.md en el proyecto para cargarla temporalmente en Zen.
