Actualizaciones

La extensión se actualiza desde Mozilla con la confirmación del navegador. El servicio local se instala desde la última versión estable de GitHub y conserva tus datos.

Las consultas a Mozilla y GitHub no envían tus capturas, notas ni claves. Puedes desactivarlas y buscar manualmente.

Para activar las actualizaciones del servicio, instala una vez la versión 1.3.2 o posterior desde la guía de instalación. Abrir la guía de instalación ↗

Preparación de notas

Elige el servicio y pega tu clave: Anaco rellena la dirección y un modelo sugerido, que puedes cambiar.

Funciona en tu ordenador: no necesita clave y nada sale de él.

Se guarda solo en el servicio local. Al cambiar la URL base, introduce la clave del nuevo servidor; la anterior no se reutiliza.

Puedes cambiarlo antes de preparar cada captura. El código relevante se conserva con su explicación en cualquiera de los modos.

Títulos, encabezados y texto de las notas nuevas. No cambia las notas que ya están en el vault.

Los podcasts largos se leen con este modelo, dos bloques a la vez. El modelo de texto elabora la nota final. Ambos usan el razonamiento elegido.

En automático se reutilizan los pies, descripciones accesibles y nombres de archivo claros. Las imágenes con descripción suficiente no se envían a visión. Los nombres se indican como pistas, no como observaciones verificadas. Las páginas de PDF y fotogramas pueden necesitar visión para comprender el contenido completo. Si ninguna imagen necesita análisis, se mantiene el modelo de texto.

Libros, PDF y vídeo

Se leen todas las páginas del libro y después se sintetizan juntas. Los lotes completados se conservan si hay que reintentar.

Motor actual: CPU · int8. La tarjeta gráfica no se utiliza en esta versión. Tiny prioriza rapidez; small requiere más tiempo y memoria. El modelo se descarga la primera vez. Se usan subtítulos cuando están disponibles.
