Anaco 1.3.2 adds update detection and a companion updater.
New permissions: alarms schedules a daily metadata check (hourly timer, 24-hour cache); https://addons.mozilla.org/* and https://api.github.com/* read public release metadata. Requests omit credentials and never send captured data. Options contains the opt-out and manual check buttons. Only stable releases are offered; network failures are shown separately from up-to-date results.
The extension update button opens https://addons.mozilla.org/firefox/addon/anaco/ . Mozilla handles installation and signing. There is no downloaded executable code in the extension.
The separate Python native companion downloads only the stable tag from the fixed samuhlo/anaco-ob GitHub repository, independently validates the release, installs into a fresh virtual environment, checks the installed version and registers the new native host. This happens only after the user presses Update local service. It preserves user settings and captures. Active work blocks the update. Services older than 1.3.2 show migration instructions.
Build and package reproduction: AMO_BUILD.md. Existing account-free capture testing: docs/amo/1.3.0-reviewer-notes.txt. No AI account is required to exercise the update settings.
